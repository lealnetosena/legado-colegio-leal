# legado-faculdade-leal

Simula o sistema legado da Faculdade Leal: matrícula, mensalidade calculada
por matérias cursadas, dependências e taxas de serviço. Monolito + banco
relacional.

É daqui que nasce o evento `mensalidade.gerada`, um por aluno, a cada ciclo
de faturamento.

Parte do case [`faculdade-leal`](https://github.com/lealnetosena/faculdade-leal).
